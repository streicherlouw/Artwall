Photo collages

Set the pace.

Playback

Folder timing defaults to 20 seconds with a 5-second fade for art, and 5 seconds with a 0.85-second fade for photos. Turn this off to use the manual timing below.

Pictures plays child folders in random order, with images inside each child folder in strict filename order. This overrides image shuffling for Pictures.

Location overlay

Locations come from the original photos. Images without GPS show no map.

Timed SplitFlap announcements pause PhotoFrame and return to the same slideshow when they expire. Untimed SplitFlap sessions replace PhotoFrame. AirPlay takes priority over both.

Temporary collection search

Choose a base folder and enter identifier words from the collage sidecars. Every word must appear somewhere in each collage; words can come from different photos. Matching ignores case and includes all confidence levels.

Artist folder searches match partial names, ignoring case and accents (for example, monet or cezanne). All words must match the same folder name. Identifier searches use exact words. Separate words with spaces or commas. Compound identifiers such as blue_sky also match the words blue and sky.

    Temporary collections last until cleared, replaced by an album selection, or PhotoFrame restarts. Rebuild the library after adding or changing image sidecars.
